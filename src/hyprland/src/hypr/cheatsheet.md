# Hyprlain keyboard

Hyprlain works like a Mac. ⌘ is Command, ⌥ Option, ⌃ Control and ⇧ Shift, and the everyday shortcuts (copy, paste, undo, find, tabs, moving through text) are the macOS ones in every app, the terminal included.

The one big difference: windows tile. A new window takes half the screen instead of piling on top, so nothing hides behind anything. Press ⌥⌘F to let a window float like it would on a Mac.

Press ⌘⇧/ to open this sheet again and q to close it.

## Everyday

| Keys | What it does |
| --- | --- |
| ⌘ Space | Spotlight: open apps (Tab switches to the calculator and files) |
| ⌥⌘ Space | Files |
| ⌃⌘ Space | Emoji |
| ⌘⇧V | Clipboard history |
| ⌃ Space | Next input source (English, Arabic) |
| Lain logo | About, Activity Monitor, Sound, Appearance, Force Quit and the power options |

## Apps and windows

| Keys | What it does |
| --- | --- |
| ⌘Tab | Back to the last app. Keep ⌘ held and press Tab again to pick another |
| ⌘⇧Tab | The same, backwards |
| ⌘` | Next window of the same app |
| ⌘Q | Quit the app (all of its windows) |
| ⌘W | Close the tab or document |
| ⌘⇧W | Close the window |
| ⌘H, ⌘M | Hide or minimise (⌘Tab brings it back) |
| ⌥⌘M | Show minimised windows |
| ⌥⌘⎋ | Force Quit |
| ⌃⌘F | Full screen |
| ⌥⌘F | Float the window, or tile it again |
| ⌥⌘P | Keep a floating window on every desktop |
| ⌘ drag, ⌘ right-drag | Move or resize a window from anywhere inside it |
| ⌥⌘ arrows | Focus the window in that direction |
| ⇧⌥⌘ arrows | Move the window in that direction |
| ⌃⌘ arrows | Resize the window |
| ⌥⌘ Return | Swap side by side and stacked |

| Keys | What it does |
| --- | --- |
| ⌃↑, or the pointer in the bottom-left corner | Mission Control |
| ⌃←, ⌃→ | Previous or next desktop |
| ⌃1 to ⌃9 | Go to a desktop |
| ⌃⇧←, ⌃⇧→, ⌃⇧1 to ⌃⇧9 | Take the window to another desktop |

## Text, in every app

| Keys | What it does |
| --- | --- |
| ⌘C, ⌘V, ⌘X | Copy, paste, cut |
| ⌘Z, ⌘⇧Z | Undo, redo |
| ⌘A, ⌘F, ⌘S, ⌘N, ⌘T, ⌘O, ⌘P | Select all, find, save, new, new tab, open, print |
| ⌥←, ⌥→ | One word left or right |
| ⌘←, ⌘→ | Start or end of the line |
| ⌘↑, ⌘↓ | Top or bottom |
| add ⇧ | Select while moving |
| ⌥⌫, ⌘⌫ | Delete a word, or back to the start of the line |
| ⌘[, ⌘] | Back, forward |
| ⌘⇧[, ⌘⇧] | Previous or next tab |
| ⌘1 to ⌘9 | Go to a tab |
| ⌘=, ⌘-, ⌘0 | Zoom in, out, actual size |

Any other ⌘ letter does what Ctrl and that letter do on Linux, so ⌘L still jumps to the address bar.

## Session

Lock Screen, Log Out, Restart and Shut Down are in the Lain menu. ⌃⌘Q and ⇧⌘Q are left to macOS on purpose, so they can never lock or log out your Mac by accident.

## In UTM on a Mac

UTM hands these shortcuts to Hyprlain only while it captures input: the window subtitle then says "Press ⌃+⌥ to release cursor". Turn on both "Capture input automatically…" options in UTM → Settings → Input and it captures whenever you click into the VM. Press ⌃⌥ to give the keyboard and pointer back to macOS, and ⌃⌥ again to return. Leave "Use Command+Option (⌘+⌥) for input capture/release" off, since Hyprlain uses ⌥⌘ shortcuts.
